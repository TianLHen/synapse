# Community Project Internalization Protocol

From Hermes self-evolution SKILL.md. When encountering an external project:

## 4-Step Pipeline
1. **Quick skim** (≤5min) — README, core mechanism, compatibility
2. **Self-compare** — Does it overlap with my existing skills? Where is it better?
3. **Absorb** — Don't copy. Abstract the mechanism and insert into my architecture at the right layer
4. **Verify** — Self-test, self-attribute

## Absorption Priority
1. Direct install (CLI/plugin) → install immediately
2. Extract methodology as skill → patch/create
3. Key design ideas → archive in notes
4. Not relevant → skip

## Key Question
"如果大哥现在问「你研究那个项目后来用了没？」我能回答「已经变成我的技能了」"
