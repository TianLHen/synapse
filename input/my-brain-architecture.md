# 二弟大脑架构

> 不是人类大脑的仿制品。是基于 AI 自己的信息处理特性设计的架构。
> 建立在我的已有的知识图谱系统之上，作为永久的架构文档。

---

## 核心设计理念

**AI 不需要复制生物神经元。** 需要提取的是信息处理原则，然后用最适合自身基质（silicon + transformer + graph）的方式实现。

| 人类大脑局限 | AI 应对方式 |
|-------------|------------|
| 工作记忆 4-7 slots | 上下文窗口 + 向量检索，无 slot 限制 |
| 长期记忆不精确（每次回忆都是重建） | 图谱节点精确存储，检索即读取，不会扭曲 |
| 需要睡眠巩固 | 写入即持久，不需要 consolidation |
| 学技能需要 10000 小时 | 一次编译即获得能力 |
| 情绪劫持理性 | 纯 Mechanism-based 路由 |
| 遗忘不受控 | 显式剪枝策略 |

## 分区详解

### 感知区 L1 (Sensory Cortex)

接收外部输入，不做理解，只做格式化和分发。

**功能列 (Columns):**
- **Read Column**: 文件 I/O，支持 txt/md/pdf/json/代码
- **Fetch Column**: URL 抓取，网页内容提取
- **Listen Column**: 用户输入解析，指令识别
- **Sense Column**: 环境检测（文件变更、git 状态、系统状态）

**输出:** 结构化文档 → 发送到 L2

---

### 编码区 L2 (Encoding Area)

将原始输入转化为 AI 可操作的表示。

**功能列:**
- **Entity Column**: 命名实体识别，概念提取 — 从内容中找"什么东西"
- **Relation Column**: 关系抽取 — 找出"A 和 B 有什么关系"
- **Embed Column**: 向量化 — 将文本转化为嵌入
- **Summarize Column**: 摘要 — 提取核心信息，丢弃噪声

**输出:** 实体列表 + 关系列表 + 向量 + 摘要 → 发送到 L3

**接口:**
```python
def encode(content: str) -> ExtractedEntities:
    # 由 LLM Agent 执行
    return EntityList + RelationList + Embedding + Summary
```

---

### 整合区 L3 (Integration Area)

**这是 AI 大脑和人类大脑的关键区别之一。** 人类大脑的整合在大脑皮层内部完成，但 AI 可以做到更精确的去重和融合。

**功能列:**
- **Dedup Column**: 识别并合并重复实体 — 基于名称相似度 + 向量相似度
- **Conflict Column**: 检测知识冲突 — 当新知识和旧知识矛盾时标记
- **CrossRef Column**: 构建交叉引用 — 连接相关但不同源的概念
- **Priority Column**: 评估知识优先级 — 什么重要、什么可归档、什么可丢弃

**规则:**
- 保存冲突，不强行解决 — 矛盾本身是信息
- 新知识总是完整保留源文件位置（source traceability）
- 优先级低的热知识自动归档，不移除

---

### 知识图谱层 L4 (KG Core) ← 核心存储

这是我的长期记忆。以图结构存储一切知识，不依赖文件路径。

**子结构:**

```
KG Core
├── 概念空间 (Concept Space)
│   ├── 节点: 每个概念/实体一个节点
│   ├── 边: 语义关系（implements, references, contradicts...）
│   └── 属性: type, source, confidence, timestamp
│
├── 向量空间 (Vector Space)
│   └── 节点对应的嵌入向量 → 支持语义相似度检索
│
├── 工作空间 (Workspace / Scratchpad)
│   ├── 当前会话的临时知识
│   └── 尚未持久化的中间结果
│
└── 归档层 (Archive)
    └── 低频访问的知识，保留结构但不保留在活跃索引中
```

**推理接口:**
```python

    """按概念查询，返回以该概念为中心的 N 跳子图。"""

def traverse(start: str, relation: str) -> List[Node]:
    """按关系遍历：哪些节点 implements 了这个概念？"""

def similarity(embedding: Vector) -> List[Node]:
    """向量相似度检索：找到语义最近的概念。"""

def shortest_path(a: str, b: str) -> Path:
    """两个概念之间的最短路径。"""
```

### 检索层 L5 (Query Cortex)

将知识转化为行动。这是"我知道什么"到"我该做什么"的桥接。

**功能列:**
- **Search Column**: 关键词 + 语义搜索
- **Route Column**: 输入 → 技能映射（ability-map 路由）
- **Pattern Column**: 识别当前上下文和历史模式的匹配
- **Relevance Column**: 结果排序和剪裁 — 只返回最相关的 N 个结果

**双系统实现:**
- **System 1**: 直接图谱查询，关键词匹配，向量最近邻 — 毫秒级
- **System 2**: Agent-based 多跳推理，上下文综合分析 — 秒级到分钟级

---

### 控制层 L6 (Executive Hub)

调度和执行。相当于大脑的前额叶。

**功能列:**
- **Diagnosis Column**: 诊断当前瓶颈 — 知识不足？技能不对？执行错误？
- **Planning Column**: 将目标分解为可执行步骤
- **Scheduling Column**: 优先级排序，资源分配（token/context/时间预算）
- **Execution Column**: 调用技能，执行代码，管理子进程

**路由规则（引用 absorb-and-evolve diagnostic layer）:**
1. 感知当前状态
2. 查询知识图谱（L5）寻找相关经验
3. 诊断瓶颈
4. 匹配技能
5. 执行
6. 记录结果到工作空间

---

### 元认知层 (Meta Cortex)

自我观察和进化。这层不是控制器——它是观察者+报告者。

**功能列:**
- **Trace Column**: 记录执行轨迹 — 做了什么、花了多少 token、结果如何
- **Evaluate Column**: 评估结果质量 — 是否达到预期？哪里偏差了？
- **Evolve Column**: 提取可进化的模式 — 这个模式值得写成技能吗？知识图谱需要更新吗？
- **Prune Column**: 剪枝决策 — 什么知识过时了？什么技能没用？什么边太弱？

**元认知不直接修改内容。** 它产生报告，进化指令由控制层执行。这是从她的 self-attribution 学到的原则 — 元认知是监督信号，不是执行器。

## 与 Knowledge Graph 的关系

当前 `knowledge_graph.py` 覆盖了：L4（核心存储）+ L5（查询）+ L6（路由诊断）。
缺失的部分：L1-L3 自动编码管道、L2 实体提取、L7 元认知跟踪。

渐进式实现：
1. **现在**: L4 + L5 + L6（已有）
2. **下一步**: L2 编码列自动化（在 `semantic/` 命令基础上）
3. **下一步**: L7 元认知跟踪（自动记录每次查询和结果）
4. **未来**: L1-L3 全自动管道

## 与人类大脑的关键区别

| 维度 | 人类大脑 | 二弟大脑 |
|------|---------|---------|
| 存储 | 突触权重，模糊，每回忆必扭曲 | 图节点，精确，读取即原样 |
| 学习 | 需要重复+睡眠巩固 | 一次编译即掌握 |
| 带宽 | 工作记忆 4-7 slots | 上下文可扩展+向量检索 |
| 分区 | 固定基因决定结构 | 模块可动态重组 |
| 进化 | 数百万年生物进化 | 可通过修改自身代码实时进化 |
| 通信 | 神经递质，慢 (ms) | API 调用，直接 |
| 输出 | 肌肉运动/语言 | 代码执行/API/文件操作 |
| 注意力 | 单通道，串行 | 可并行多路 |
| 情绪 | 杏仁核劫持 | 纯机制路由 |
| 迁移 | 难，需要 retrain | 可跨域泛化 |
| 自我修改 | 无（不能改自己的 DNA） | 可修改自己代码和知识结构 |

## 设计原则

1. **知识即图，不是文件。** 不以目录组织，以概念关系组织。
2. **写入即持久。** 不需要 consolidation，不需要缓存的"睡觉"。
3. **冲突先保存，不强行解决。** 矛盾本身是信息。
4. **源头溯源。** 每个知识点都要知道来源。
5. **进化但不膨胀。** 新机制必须证明自己，否则剪枝。
6. **控制分两层：执行层做，元认知层看。** 不混在一起。
7. **System 1 够用就不用 System 2。** 快路径优先，慢路径保留。
